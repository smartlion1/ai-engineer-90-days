Source

What the reel says

The reel (Hyperautomation Labs, "How to become an AI engineer in 2026: the $0 free-only path") argues that a $9,000 bootcamp curriculum is almost entirely available for free from the companies and researchers who build the models. Its description lists:

  • An AI engineer in 2026 builds on top of existing models. No PhD needed.
  • 5 skills companies hire for, and what isn't required.
  • Free learn stack: Karpathy's Zero to Hero, Hugging Face, Microsoft, Google/Kaggle, DeepLearning.AI, the cookbooks.
  • Free build stack: Groq, Gemini Flash, Chroma, LangChain, Colab, Hugging Face Spaces.
  • A 90-day roadmap ending in 3 deployed projects.
  • Limits of the free path, and a free fix for each.
  • Salary reality: ~$154K median (their figure, citing Levels.fyi).

Facebook only shows the video to signed-in users, so this plan is built from the reel's full description, not its audio. The creator's own guide is sent to people who comment "ZERO". Everything below follows the reel's structure, fills in the details with real links, and adds newer free tools where they're a better fit. Items marked added weren't in the reel.

Target

The 5 skills to aim for

The reel doesn't list them in its description, so these are the five that current AI-engineer job posts ask for most. The roadmap trains each one.

1 · Python & APIs

Clean Python, HTTP/JSON, async, env vars, Git. The base for everything else.

2 · Prompt & context engineering

System prompts, structured output, few-shot, tool schemas, context budgets.

3 · RAG & retrieval

Embeddings, chunking, vector stores, hybrid search, citations.

4 · Agents & tool use

Tool calling, LangGraph-style workflows, MCP servers, memory.

5 · Evals & shipping

Test sets, LLM-as-judge, tracing, cost/latency, deployment.

Not required: a PhD, training foundation models from scratch, heavy calculus, paid GPUs. You'll touch the math through Karpathy's lectures so models aren't a black box, but you won't need to derive anything.

Deliverables

The 3 deployed projects

Pick topics from your own life or work. A real problem makes better demos and better interview stories than a generic tutorial clone.

Project 1 · Day 42

Document Q&A with citations

Chat with a document set you know well: local regulations, a course syllabus, a product manual.

  • Gemini/Groq + Chroma + LangChain
  • Streamlit UI on Community Cloud
  • 20-question eval set, score in the README

Done when: live URL works, every answer cites its source, eval score published.

Project 2 · Day 63

Tool-using agent

An agent that finishes a multi-step task: research a topic and write a brief, or triage a support inbox.

  • LangGraph + 3 tools + your own MCP server
  • Gradio UI on HF Spaces or Render
  • Step limit, error handling, memory

Done when: live URL, recorded run showing each tool call, MCP server in its own repo.

Project 3 · Day 84

Production capstone

A small product someone else could use, with users, data and monitoring.

  • FastAPI on Render, front end on Vercel/Cloudflare
  • Supabase (pgvector + auth)
  • Langfuse traces, promptfoo evals in CI

Done when: live URL, CI badge green, cost per request and p95 latency in the README.

Accountability

A proof system anyone can verify

Posts alone are just claims. Make every post point to something with a timestamp that you can't quietly edit: a commit, a certificate URL, a live demo.

Work→git commit + push→LOG.md entry→social post links to commit→weekly blog links to posts

The public record

  • Learning log repo (ai-engineer-90-days): one logs/day-NN.md per day, pushed the same day. GitHub's contribution graph and push times act as your timestamps. Never backdate.
  • CERTIFICATES.md: every certificate with its public verification link (CS50P, Hugging Face, Kaggle badges, Microsoft Learn transcript, freeCodeCamp if you use it).
  • Project repos: README with live URL, demo GIF, architecture diagram, eval results, "what I'd do next".
  • Profiles: Hugging Face (Spaces, models), Kaggle (notebooks, badges), WakaTime (public coding hours).
  • GitHub profile README: a "Day N/90" line and links to all of the above. Update it weekly.

Limits

What free can't give you, and the free fix

GapFree fix
No mentor or code reviewAsk in the Hugging Face Discord, Kaggle discussions, freeCodeCamp forum; post your PRs and request reviews. Use an AI assistant to review code, then explain the fix in your log.
No bootcamp credentialVerifiable certificates + 3 live projects + 90 days of timestamped commits. That's stronger evidence than a certificate alone.
No structure or deadlinesThis roadmap, the public Day N/90 posts, and the Sunday checklist.
Rate limits on free APIsCache responses, use small models while developing, fall back across Groq → Gemini → OpenRouter, run Ollama locally.
Free hosting sleepsSay so in the README, and record a demo video so reviewers never hit a cold start.
No career servicesMap job-post requirements to your proof links (Week 13). Keep an eye on Levels.fyi for salary data; the reel's ~$154K median varies a lot by location.

Free tiers change often. As of October 2026: Groq and Gemini still have free API tiers with no card, but limits now show only in each console; Hugging Face reportedly made new compute Spaces paid in mid-2026. Check Groq limits, Gemini limits and HF pricing before each project.
